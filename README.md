## Como usar 

A continuacion se detallan los pasos para compilar y ejecutar el programa.

### Compilacion
```cargo build```

### Como correr
Para correr el sevidor, con <n> siendo el numero de puerto
```cargo run --bin server <n>```

Para correr el cliente
```cargo run --bin client <n>```

Para correr la ui
```cargo run --bin gui <n>```

## Como testear
```cargo test```
